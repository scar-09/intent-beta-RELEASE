# Intent

**Pause before you act.**

Intent is an Android app that intercepts restricted apps during set time windows, forcing a moment of reflection before you decide to open them.

Currently in closed beta.

---

**Requirements**
- Android 7.0 or higher
- Accessibility permission (required for interception)

**Installation**
1. Download the APK from the releases page
2. Enable "Install from unknown sources" in your Android settings
3. Install and follow the in-app setup
